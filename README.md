## 📘 Project Overview
This repository contains the **mockup version** of **BarChain**, a prototype Barangay Information Management System developed under **Capstone Project 1**.  
It aims to **digitize barangay operations and administrative records** through a secure and modernized information system.

At this stage, BarChain focuses on demonstrating **user interface design**, **data flow**, and **system logic** prior to blockchain integration.

---

## ⚙️ Current Setup
- Data is temporarily stored in **JSON files** to simulate CRUD (Create, Read, Update, Delete) operations.  
- **Blockchain technology is not yet implemented** — this build functions solely as a mockup.  
- Emphasis is on **interface design**, **mock data handling**, and **system presentation**.


## 🧩 Purpose of the Mockup
The mockup version serves to:
- Present a **functional prototype** of the Barangay Information System.  
- Lay the groundwork for **blockchain and database integration** in later stages.  
- Demonstrate **digital transformation feasibility** at the barangay level.


## 🔒 Future Development
Future improvements will include:
- **Blockchain integration** for verifiable and immutable data.  
- Migration from JSON to a **distributed, secure database**.  
- **Smart contract implementation** for automated record validation.


## ⚠️ Disclaimer
This repository is a **mockup version** developed for academic and demonstration purposes only.  
All data stored in JSON files is **temporary** and should **not** be used for actual barangay operations.  
Blockchain features will be implemented in subsequent versions.
